# Nexora — AI Automation Homelab

A self-hosted AI automation project built to explore
Linux infrastructure, AI agents, Python, and cybersecurity.

## About This Project

Nexora is my personal homelab project focused on
building practical, self-hosted AI automation.

## Technology Stack

- Ubuntu Server
- Docker
- Python
- Ollama and local language models
- Open WebUI
- REST APIs
- systemd services and timers
- ntfy notifications

## Current Features

- Self-hosted AI assistant
- Technical stock discovery
- Social sentiment research
- Swing-trading risk analysis
- Alpaca paper-account integration
- Automated market research
- Flight monitoring and notifications

## Development Roadmap

- Improve autonomous AI agents
- Expand stock discovery and research
- Develop risk-controlled paper trading
- Build a personal job-search assistant
- Improve monitoring and observability

## Security

This public-facing project documentation uses
sanitized examples only.

API credentials, personal information, and private
infrastructure configurations are excluded.

## Project Status

Actively under development.
